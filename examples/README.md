# Original example methodology

These examples cover four distinct visual families so the skill demonstrates conceptual range rather than palette swaps:

| Example | Family | Product promise | Recognition anchor | Proposed groups |
| --- | --- | --- | --- | ---: |
| Quiet Tide | Layered abstract | calm focus | wave embracing a sun | 3 |
| Parcel Pulse | Tactile object | track a package | parcel crossed by scan band | 3 |
| Mood Lantern | Mascot | reflect on feelings | lantern character with warm core | 4 |
| Orbit Stack | Liquid Glass system | layered spatial notes | three diamonds and a spark | 4 |

Workflow used:

1. Analyze the private reference set into broad visual families.
2. Write one fictional product brief per family.
3. Use selected reference images only for broad style qualities.
4. Explicitly prohibit copied symbols, compositions, palettes, and brand identity.
5. Generate one square concept per call using the built-in image-generation tool.
6. Inspect each output and resize the retained concept master to 1024 × 1024.
7. Iterate on the retained whole-icon concept before spending effort on layers.
8. Record explicit design approval before production reconstruction or Icon Composer.
9. Record the prompt, role, rationale, production reconstruction plan, and evidence boundary.

Quiet Tide demonstrates deliberate SVG reconstruction and a real Icon Composer/Xcode/Simulator path for geometry that survives separation. Mood Lantern demonstrates when a shipping icon needs a newly approved Composer-adapted concept—or an explicitly selected flattened fallback—because shared glow and shading do not survive mechanical separation. The other concept masters remain flat PNGs and do not claim production validation.
