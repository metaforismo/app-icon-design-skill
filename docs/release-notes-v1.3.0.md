# App Icon Studio v1.3.0

Version 1.3.0 separates the skill’s identity from its teaching examples and simplifies the public presentation.

## What changed

- Added a dedicated folded-ribbon App Icon Studio mark for the Codex skill UI and repository.
- Replaced the Mood Lantern social banner with the new identity.
- Removed the rejected Mood Lantern reconstruction assets and older layer-first instructions from the main README.
- Reduced the README to the current image-first workflow, installation, requests, included capabilities, QA, and evidence boundaries.
- Preserved advanced Icon Composer and platform-delivery material as optional references rather than the primary path.

## Evidence boundary

The new identity assets were generated with the built-in Imagegen tool and inspected at 1024 px, 400 px, and 1280 × 640. Repository tests, canonical skill validation, packaging, installed-skill validation, GitHub rendering, and CI are reported separately after publication. Icon Composer, Xcode, Simulator, device, App Review, and conversion outcomes were not exercised for the new identity.
