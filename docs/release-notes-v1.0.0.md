# App Icon Studio Skill 1.0.0

The first public release turns icon exploration into a reproducible production workflow.

Highlights:

- Invoke with `Use $design-app-icons to ...`.
- Generate original concept directions with Imagegen and retain prompt provenance.
- Choose deliberate SVG reconstruction or one-element-per-image raster assembly.
- Author and inspect current Default, Dark, Mono, Clear, and Tinted paths without confusing previews with device evidence.
- Use the included static QA CLI for platform dimensions, opacity, heuristic masks, small-size assets, and appearance stress tests.
- Study a real `.icon` document and XcodeGen fixture that built and rendered in an iOS 26.5 Simulator.
- Prepare controlled Product Page Optimization hypotheses without promising conversion lift.

The release archive contains only the installable `design-app-icons` skill. The repository also contains source examples, evidence, tests, research notes, and reproducible packaging tools.

## Evidence boundary

- **Validated:** repository tests; canonical skill validation; Quiet Tide Icon Composer export; iOS 26.5 Simulator build and Home Screen rendering.
- **Prepared:** skill archive, checksums, sample PPO plan, Mood Lantern raster layer proof.
- **Not tested:** physical devices, App Review, live App Store experiments, or conversion outcomes.
